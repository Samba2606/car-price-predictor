# 🚗 Car Price Predictor

Predicts used car market prices instantly.
Live Demo: https://car-price-predictor-1-qj1z.onrender.com

## Features
- Predicts price based on brand, year, fuel type, mileage
- 90%+ accuracy using Linear Regression
- Dynamic dropdowns from real dataset

## Tech Stack
- Python, Scikit-Learn, Pandas, Streamlit, Render
